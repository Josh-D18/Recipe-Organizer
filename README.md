# Recipe Sandbox (TypeScript MERN)

This repo is intentionally imperfect — built for interview pair-debugging.

### Requirements

- Node 18+
- MongoDB running locally on mongodb://localhost:27017/recipe-sandbox (or change in server/.env)

### Quick start (dev)

Open two terminals:

**Server**

```
cd server
npm install
npm run dev
```

**Client**

```
cd client
npm install
npm start
```

The client runs on http://localhost:3000 and the server on http://localhost:4000 by default.
